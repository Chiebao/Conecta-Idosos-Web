# Conecta Idosos — Site de ONG de Inclusão Digital

Site para uma ONG **fictícia** de inclusão digital da terceira idade, com cursos, oficinas, galeria de ações e cadastro de voluntários e doadores. Trabalho acadêmico da disciplina de Desenvolvimento Web do curso de Análise e Desenvolvimento de Sistemas.

🔗 **Site no ar:** [conecta-idosos-web-qj5v.vercel.app](https://conecta-idosos-web-qj5v.vercel.app/)

![Preview do site](./Captura%20de%20tela%202025-10-18%20115524.png)

---

## Funcionalidades

- **Três páginas:** início, projetos e cadastro
- **Navegação em estilo SPA:** as páginas são carregadas sem recarregar o site
- **Formulário de cadastro** com validação de e-mail e mensagens de erro e sucesso
- **Dados salvos no navegador** com `localStorage`, simulando um banco de dados
- **Menu responsivo** com botão hambúrguer e animação de entrada dos elementos ao rolar a página
- **Layout responsivo** para celular, tablet e desktop

## Tecnologias

`HTML5` `CSS3` `JavaScript` `Vercel`

O CSS é dividido por responsabilidade: `base.css` (variáveis, cores e tipografia), `layout.css` (estrutura e grid), `componentes.css` (botões, cards e formulários) e `responsive.css` (breakpoints).

## Como executar

Abra o `index.html` no navegador ou acesse o site publicado.

## Observação

A ONG, os contatos e as fotos são fictícios, criados para o trabalho acadêmico.
